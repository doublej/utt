Hold a key, speak, release. The text lands at your cursor. Nothing leaves the
machine.

This is the first release that installs itself, and it exists to prove that it
does. Nothing in the app changed.

## What is different

The release notes you are reading are carried inside the update feed rather than
fetched from a second address. Sparkle worked out that address from the feed's
own location, which is a file in this repository and not a folder of notes, so
the pane you would have read 0.5.0's notes in was empty. They travel with the
update now.

If you got here by clicking **Install Update** rather than by downloading a disk
image, the thing this release was made to test worked.
